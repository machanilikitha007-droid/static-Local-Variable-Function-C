# Static Local Variable in Function

This program demonstrates how a static local variable keeps its value
between multiple function calls.

## File

static_function.c

## Concepts Used

- Function call
- Static local variable
- Function definition
- Local variable

## How to Run

gcc static_function.c -o static_function
./static_function

## Sample Output

Function called 1 time(s)
Function called 2 time(s)
Function called 3 time(s)
